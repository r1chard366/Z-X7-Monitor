## 7. 屏幕不亮的根因（19:00 前后补测，已修复）

现象：官方程序关掉后屏幕全黑；本工具单独跑也全黑；两者同时跑再关官方，屏幕停在最后一帧。

排查过程：

| 步骤 | 结论 |
| --- | --- |
| `HidP_GetCaps` | 输入/输出报告均为 **65 字节**（= 1 字节 Report ID + 64 字节数据） |
| `HidP_GetValueCaps` | ReportID = 0（该字段读取不可靠，后面用点灯实测否掉了） |
| 输入报告监听 | 设备不回显、不应答，无法用读取确认 |
| **点灯实测** | 三种候选线上格式各 20 秒：`00+报文`(61℃) / `报文+00`(62℃) / `01+报文`(63℃) |

结果：**只有「报文 + 尾部 0x00」点亮屏幕**，屏上显示 62℃，与测试值 62.2℃ 对上。
说明官方 JS 里 64 字节数组的**首字节 `0x01` 是 Report ID**，不是数据头；
hidapi 把缓冲首字节当 Report ID，所以正确写法是「64 字节数组原样 + 一个 0x00 补位」。

修复：

- `src/hid_device.py`：新增 `build_wire_payload()`，输出 `report + b"\x00"`（65 字节）；
- 新增 `src.cli doctor`：一条命令看清设备、wmi、LHM、ACPI、当前读数；
- `src/controller.py`：温度模式下所选通道没有数据时，自动切到有数据的通道。

修复后实测：`live --mode temp --channel gpu` → 屏幕显示 **34–35℃**（GPU 实时温度），
与控制台读数一致，重启后仍然正常。
